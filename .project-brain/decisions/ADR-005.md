# ADR-005 — Skor tahtası altyapısı: Cloudflare Workers + D1, Google + Apple kimlik

## Karar
Global skor tahtası SPEC §7 mimarisiyle kurulur: Cloudflare Workers (API) + D1
(users/scores). Kimlik: Android+iOS'ta Google ile Giriş; iOS'ta ayrıca Sign in with
Apple (Guideline 4.8). Worker Google/Apple token'ını doğrular, kendi 30 günlük
HMAC-JWT oturumunu verir. Zip'teki eski Game Center/Play Games köprüsü
(reference/leaderboard.js + LEADERBOARDS.md) kullanılmaz; yalnızca davranış ilkeleri
(kuyruk ≤50, yalnız en yüksek skor, sessiz çevrimdışı düşüş) korunur.

## Gerekçe
- Kullanıcının devir brifingi §7 bunu açıkça tanımlar (tek kaynak).
- GC/PGS yaklaşımı yayınlama öncesi konsol kurulumu ve platform ayrımı gerektirir;
  Cloudflare ücretsiz katmanda tek arka uçla iki platformu kapsar.

## Sonuçlar
- `worker/` altında bağımsız deploy edilir (bu repoda geliştirilir; deploy/publish
  release skill kapsamındadır).
- TD-002 (tahtada görünecek ad) çözülene kadar display_name = hesap adı varsayılanı.
