# ADR-001 — Marka: Neon Kule → Stack Tower Game

## Karar
Proje adı **Stack Tower Game** oldu (kullanıcı kararı, 2026-10-24). Uygulama görünen
adı, menü logosu, mağaza metinleri ve tüm kullanıcıya görünür metinlerde "Neon Kule"
kullanılmaz; "Stack Tower" ana marka, "GAME" tamamlayıcıdır.

## Sonuçlar
- Dart paket adı: `stack_tower_game`; geliştirme kimliği `com.stacktower.game`
  (yayın kimliği TD-001 açık kararı).
- Kayıt anahtarı: `stacktower_save_v2` (şema SPEC §5 ile birebir aynı).
- Eski Capacitor uygulamasının localStorage'ı (`neonkule_save_v2`, `neonkule_best_v1`)
  Flutter kurulumundan erişilemez (farklı sandbox); v1→v2 migration yeni kurulumda
  geçersizdir. Skorlar Cloudflare tahtasıyla ilişkilendirilebilir (ileri aşama).
- `reference/` altındaki kaynak dosyalardaki "Neon Kule" dizeleri tarihi kayıttır;
  port sırasında Dart tarafına çevrilmez.

## Alternatifler
- Eski WebView verisini okuyarak migration: karmaşık ve kırılgan; uygulama mağazada hiç
  yayınlanmadığı için gerçek kullanıcı verisi yok → reddedildi.
