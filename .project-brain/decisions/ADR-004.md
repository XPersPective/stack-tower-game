# ADR-004 — State yönetimi: Provider + ChangeNotifier

## Karar
Uygulama durumu: `provider` paketi + `ChangeNotifier` (kayıt/ekonomi `SaveStore`,
oturum `SessionStore`, ses `AudioController`). Oyun motorunun frame durumu widget
dışında tutulur (painter'a referansla); ekranlar `setState`/`Consumer` ile bağlanır.

## Gerekçe
- SPEC §4: "State yönetimi abartılmayacak: Provider/Riverpod seviyesi yeter."
- Ekran sayısı az, veri akışı tek yönlü (kayıt → ekranlar); Riverpod'un öğrenme/
  tutarlılık maliyeti bu ölçekte gerekmez.
