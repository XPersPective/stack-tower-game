## Objective
"Ses: her olay için ses (bırakma, mükemmel seri, ödül, kutu, tören) + sessize alma"
(game.js tone() seti) — ADR-003 yaklaşımı.

## Steps
1. `tools/gen_sounds.dart`: game.js tone() parametrelerini (freq→endFreq, dur, type
   sine/triangle/square/sawtooth, vol, delay) birebir sentezleyen saf Dart WAV üreteci
   (osilatör + exponential zarf 0.012s attack, 0.0001 floor; 44100Hz 16-bit mono).
   Tonlar: place(240→110,tri,.12,.22), perfect(b=640+combo*45 tavan1200 + b*1.5 ikinci,
   sine), win(523,659,784,1047 tri ardışık .11), lose(340→70,saw,.55), coin(1180→1560,
   square,.09,.10), box(420 + 660/880/1320), shield(320→960,tri,.22), start(480→900,tri,.16).
   Kombo tonu combo=1..8 için önceden üretilir (perfect1..perfect8).
2. `flutter pub run` yerine `dart run tools/gen_sounds.dart` → `assets/sounds/*.wav`.
3. `lib/game/audio.dart`: `AudioController` — preLoad, play(event), mute toggle
   (kalıcı: stacktower_muted), perfect(combo) doğru dosyayı seçer.
4. Motor + ekranlar ses çağrılarına bağlanır (gameplay.dart'e AudioController enjekte).
5. `test/audio_test.dart`: dosya mevcut + boyut >0; mute durum kalıcılığı (sahte depo).
