## Objective
SPEC §7 backend'i: Workers + D1; Google/Apple kimlik doğrulama, global tahta uçları.

## Steps
1. `worker/wrangler.toml` (D1 binding `DB`), `worker/schema.sql` (SPEC §7.3 birebir:
   users + scores + idx_board_score).
2. `worker/src/index.ts`: uçlar — POST /auth/google, POST /auth/apple, GET /me,
   GET /leaderboard?board=daily&day=n|endless (ilk 100 + kullanıcının sırası/skoru),
   POST /score (upsert yalnız excluded.score > scores.score; gün UTC'de sunucuda;
   sanity tavanlar daily≤2000 endless≤100000; kullanıcı başına ~10 istek/dk sınırı),
   DELETE /account (users+scores silme). Her uç (auth hariç) HMAC-JWT oturum doğrular
   (30 gün exp). CORS yalnız uygulama kökeni (capacitor/flutter http).
3. Google doğrulama: JWKS https://www.googleapis.com/oauth2/v3/certs (kid seçimi,
   Cache-Control önbelleği, bilinmeyen kid→bir kez yenile), alg=RS256 + imza
   (Web Crypto subtle) + aud=CLIENT_ID env + iss + exp. Apple: Apple JWKS + client_id.
   sub = kimlik (e-posta saklanmaz).
4. `worker/src/jwt.ts`: oturum JWT üret/doğrula (HMAC-SHA256, sub/name/iat/exp).
5. `worker/test/`: vitest + @cloudflare/vitest-pool-workers — D1 miniflare üzerinde:
   auth akışı (sahte RSA anahtar seti ile imzalı token), skor monoton artırım, gün
   UTC hesabı, hız sınırı, hesap silme, leaderboard sıralama + kendi sırası.
6. README: deploy adımları (wrangler d1 create, secret'lar: SESSION_SECRET,
   GOOGLE_CLIENT_ID, APPLE_*), ücretsiz katman notu.
