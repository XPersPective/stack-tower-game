## Objective
Kullanıcı isteği (2026-10-30): "Kapsamlı bir şekilde premium düzeyde uygulu
bitir. Kullanıcı için zevkli görseller harika olsun. Efektleri her şeyiyle
beraber. Test etme / emülatörde test etme. Üretim düzeyini bitirmeni istiyorum."

İki eksen: (1) PREMIUM GÖRSEL + EFEKT katmanı tüm ekranlarda; (2) ÜRETİM
(RELEASE) sertleştirme — release derlemesi gerçekten yayına hazır olsun.

## Steps
1. **Paylaşılan premium UI kiti** (`lib/ui/premium_kit.dart`): GlassPanel,
   GradientButton, PressScale, PressableCard, CountUpText, GradientTitle,
   FadeSlideIn, InfoChip, PremiumHeader, ResourceChip, CoinGlyph, StarGlyph.
2. **Canlı arka plan** (`lib/ui/aurora_background.dart`): aurora şeritleri,
   paralaks yıldız alanı, uzak gezegen, vinyet — tema rengine göre.
3. **Ortam animasyonu kapısı** (`lib/ui/ambient.dart`): `AmbientMotion`.
   Testte kapalı (deterministik `pumpAndSettle`), üretimde açık.
4. **Ekran yükseltmeleri**: menü, mağaza, ödül odası, görevler, pazar, ayarlar,
   harita, önizleme → cam paneller, gradient başlıklar, kademeli giriş.
5. **HUD**: cam düğmeler, pop animasyonlu skor, parlayan hedef çubuğu,
   kombo rozeti (ısıya göre renk), kalkan göstergesi.
6. **Akış overlay'leri**: konfeti + ışık halkası arka planı, hediye kutusu
   animasyonu, sayaç animasyonlu ödül, cam tahta satırları.
7. **Yeni arayüz sesleri** (6): tap, whoosh, reward, unlock, error, pop.
8. **Üretim sertleştirme**: INTERNET izni, release imzası, R8, ProGuard,
   Android 12+ splash, iOS bundle id + entitlements + koyu tema.
