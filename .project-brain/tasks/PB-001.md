Flutter projesi, Stack Tower Game kimliği, neon tema tokenları, Inter fontu, dikey kilit.

## Steps
1. `flutter create --org com.stacktower --project-name stack_tower_game --platforms android,ios .`
2. `pubspec.yaml`: `flutter_lints`, `provider`, `shared_preferences`, `audioplayers` bağımlılıkları; `assets/fonts/` + `assets/sounds/` klasörleri tanımla.
3. `reference/www/fonts/Inter.woff2` → TTF dönüştür, `assets/fonts/` altına koy; `OFL.txt` lisansını kopyala; pubspec `fonts:` bölümüne ekle.
4. `lib/theme/tokens.dart`: THEMES 10 paleti (id/name/hues/bg/glow/weather/silhouette — levels.js THEMES birebir), neon renk sabitleri, `AppTheme.build()` (koyu zemin, Inter, glow stilleri).
5. `lib/main.dart`: `SystemChrome.setPreferredOrientations` dikey kilit, immersive edge-to-edge, tema + `MaterialApp` + geçici placeholder menü ekranı ("STACK TOWER").
6. Android `AndroidManifest.xml`: `screenOrientation="portrait"`; iOS `Info.plist` portrait kilit.
7. Uygulama adı: Android `android:label="Stack Tower Game"`, iOS `CFBundleDisplayName`.
