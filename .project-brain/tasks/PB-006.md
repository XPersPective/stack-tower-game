## Objective
Oyun ekranını oynanabilir hale getir: dokun→bırak, HUD (‹ÇIK, skor, seri, ilerleme,
kalkan rozeti, ses), kalkan/sürpriz akışı, sonuç olaylarının üst katmana iletilmesi.

## Steps
1. `lib/screens/play_screen.dart`: Ticker yönetimi (SchedulerBinding), GestureDetector
   (tap→engine.drop), boyut değişimi→engine.resize, anlık HUD değerleri ValueListenable
   veya AnimatedBuilder ile (her frame setState değil).
2. HUD bileşenleri `lib/screens/widgets/`: geri düğmesi (PopScope + onay), skor + hedef
   ilerleme çubuğu, kombo göstergesi, kalkan rozeti (kalan sayı), ses düğmesi; safe-area.
3. `lib/game/game_session.dart`: seviye başlatma (surprise uygula: coinStart→para ekle,
   shieldUp→2 kalkan, doubleCoins→ödül ×2 bayrağı), motor olay akışı (place/shield/win/
   lose) → completeLevel + recordDaily + kayıt anında yaz; win/lose sonrası result akışı
   callback'i; endless modda rekor takibi.
4. Karanlık bölümde HUD okunabilirliği (glow/contrast) koru.

## Acceptance
- [ ] [machine] widget test: tap→drop tetiklenir; kazanma yolunda result event gelir
- [ ] [interaction] dokunarak 10+ blok dizilebilir; kalkan bir kez kurtarır; hedefe ulaşınca kazanma
- [ ] [visual] HUD tüm oyunlarda okunur; karanlık bölümde kontrast korunur (ekran kaydı)
- [ ] [accessibility] dokunma hedefleri ≥48dp; geri düğmesi çift dokunma ile yanlışlıkla çıkışı engeller
