## Steps
1. Uygulama ikonları: `reference/assets/icon-1024.png`'den flutter_launcher_icons ile
   Android + iOS seti; adaptive icon (foreground/background); splash (koyu zemin +
   STACK TOWER logosu).
2. TD-001 çözülmüşse paket kimliğini güncelle (varsayılan com.stacktower.game);
   version 1.0.0+1; Android versionCode kuralını README'ye işle.
3. `store/`: google-play.md + app-store.md metinlerini Stack Tower Game'e uyarla
   (isim/açıklama/etiketler; reference/store/ köstek); gizlilik politikası
   (reference/store/gizlilik-politikasi.html) → sunucuda saklanan veriler (sub, ad,
   skorlar), silme hakkı, iletişim — Play Data Safety + App Privacy beyan tabloları.
4. CI: `.github/workflows/build.yml` — flutter analyze+test, appbundle artifact;
   iOS Archive ayrı macos işi (commented/optional).
5. README: kurulum (flutter pub get, test), ses üretimi (dart run tools/gen_sounds.dart),
   worker deploy özeti, yayın öncesi kontrol listesi (SPEC §8 manuel cihaz listesi).
