## Steps

   `RANGE_FACTOR=2.1`, `OVERSHOOT=1.05`; `clamp`; `resolveDrop(moving, top, tolerance)`

   (minX=x-w*1.05, maxX=minX+travelRange); `speedMultiplier(placed)=min(3,0.9+placed*0.055)`;

   sınırda yön değiştir); `growthWidth(w, baseW, combo)` (combo%4==0 && combo>0 →
   min(baseW, w*1.04)).
2. `Block` (x,w) ve `Moving` (x,w,dir) değer tipleri.
3. `test/drop_core_test.dart` (JS test.js CORE senaryolarından): tam üstüne → perfect;
   tol sınırı (|Δx|=tol mükemmel, tol+0.01 değil); sola/sağa kayma → doğru cuts ve
   placed overlap; sıfır örtüşme → ok:false; stepMoving sınır sekmesi (minX/maxX'de
   dir çevirir, x dışarı çıkmaz); speedMultiplier tavan 3; growthWidth 4. mükemmelette
   büyür (HIZLI/PATRON kontrolü motor katmanında — growthAllowed).
