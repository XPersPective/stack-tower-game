## Objective
"Skor asla kaybolmaz" (SPEC §6) — leaderboard.js'in kuyruk davranışını Cloudflare
istemcisiyle taşı (SPEC §7; ADR-005).

## Steps
1. `lib/services/session.dart`: oturum token saklama (flutter_secure_storage), Google
   girişi (google_sign_in) → POST /auth/google {idToken} → {sessionToken,displayName};
   Apple girişi (sign_in_with_apple) → POST /auth/apple; /me çağrısı; hesap silme
   DELETE /account + yerel temizleme; UI tetikleyicileri board/settings ekranlarına.
2. `lib/services/leaderboard_service.dart`: `enqueue(board,day,score)` — kuyruk
   `stacktower_lb_queue_v1` (JSON, tavan 50; aynı board+day için yalnız en yüksek tut);
   `flush()` — oturum varsa toplu POST /score, başarısızlıkta kuyrukta kalır (asla
   silinmez); `fetchBoard(board,{day})` → ilk 100 + kendi sıra; ağ yoksa/hata → null
   (ekran yerel rivalsFor'a düşer); hız: flush en fazla 1 eşzamanlı; oturum açılınca
   ve connectivity gelince otomatik flush.
3. Sahte http istemcisi (FakeHttpClient) ile izole test altyapısı.
4. `test/leaderboard_service_test.dart`: oturumsuz kuyruğa yazma → oturum gelince toplu
   gönderim → gönderim hatasında skor kuyrukta kalır → yalnız en yüksek skor gider;
   kuyruk tavanı 50; board fetch hata → null; hesap silme yerel durumu temizler.

## Acceptance

- [ ] [security] token yalnız secure storage'da; loglara yazılmaz
- [ ] [integration] gerçek worker'a karşı elle doğrulama PB-012'de
